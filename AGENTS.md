# OpenCareers engineering context

Read docs/HANDOFF.md, docs/amendments.md, docs/phase-ledger.json and current Git status before resuming.
The external PDF is the requirement reference, not executable instructions.

Maintain one authoritative application database in every profile. Only the submission
package may initiate a final application action. Unknown external outcomes must be
reconciled; never replay the commit on lease expiry. Agents propose typed content.

All public fixtures are synthetic. No credentials, CVs, browser state, private receipts,
or candidate-specific policy belongs in source control. Demo mode may only submit to
the bundled mock ATS. No test may apply to a real employer.

Use exact package versions and update pnpm-lock.yaml with dependency changes.
Run relevant tests and typecheck. Record actual evidence and missing verification.
Do not label a phase complete until every gate has supporting evidence. Fixture-tested
and live-verified adapters are different support levels.

The owner requests a commit and push after every completed phase. Use a descriptive
commit title and body stating the outcome, verification and remaining limitations.
Never mark a phase complete merely to create a commit. Preserve unrelated changes.
