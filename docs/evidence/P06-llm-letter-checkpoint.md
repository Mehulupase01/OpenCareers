Checked 2026-09-27. This is a code and synthetic-fixture checkpoint, not a
live cover-letter quality or genuine-submission claim.

The LLM proposal sends the bounded vacancy description, exact matched
requirements and already-approved contribution text. Identity and
work-authorization facts are withheld. The request pins one explicit free
model/provider with no fallback, strict JSON schema, zero retention and denied
data collection. Model output can reorder/select approved contribution IDs
and write role-focused motivation, but cannot add a new contribution fact.
The compiler rejects mismatched packet identity, changed opening, unknown or
duplicate evidence, ungrounded numbers, another employer, markup, links and
common unsupported self-claims. The independent packet validator then checks
claim revisions and rendered content. The immutable manifest records model,
provider and response hash.

prepare tasks only while a free route is ready. A sent 429 remains charged and
enters bounded backoff. The private submission repository requires LLM letter
provenance for external adapters before creating a final-action intent. The
synthetic mock workflow retains deterministic packets.
